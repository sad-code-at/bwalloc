# LaTeX build

IEEEtran conference format, the right template for the ICCIT / TENCON /
WCNC-workshop tier this work targets.

```bash
pdflatex paper && bibtex paper && pdflatex paper && pdflatex paper
```

Verified with MiKTeX 24.1 / pdfTeX 4.18: 0 errors, 0 undefined references,
0 missing figures, 0 overfull boxes above 20pt. Output is 9 pages.

`paper.tex` is the submission document and `refs.bib` its bibliography.
Figures are read from `../figures/` via `\graphicspath`, so the figures stay
in one place and are regenerated by `notebooks/07_paper_figures.ipynb` from
`experiments/results/` alone.

`../paper.md` remains the readable source of record; the two are kept in sync
by hand, so edit one and port the change.
